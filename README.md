# Group Pet Grooming Salon Management System

## Project Overview 
This is a Java-based Command Line Interface (CLI) application designed to manage the workflow of a Pet Grooming Salon. It simulates the entire client journey, from booking an appointment to the final record keeping, covering **16 distinct processing steps.**

The application features an interactive menu system, visual progress bars, and detailed status updates for each stage of the grooming process.

## Features
* **Appointment Booking**: Create new appointments with Client Name, Pet Name, Breed, and Service Type.
* **Workflow Management**: detailed tracking of the 16-step grooming process (e.g., Check-in, Bathing, Styling, Payment).
* **Visual Progress Tracking**:
  * Visual progress bars (e.g., [■■■■■-----------]) to show completion status.
  * Detailed breakdown of current actions, staff involved, and specific salon areas.
* **Interactive Menu**: Clear screen transitions and intuitive navigation.
* **Fast-track mode**: Option to simulate the completion of all remaining steps automatically.
